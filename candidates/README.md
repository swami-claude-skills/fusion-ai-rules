# Candidates

Proposed rules waiting for review, one folder per batch (for example `2026-11-izzy-symmetry/`).
Each file has a `C-YYYY-MM-NN` id; it gets an `R##` id only when accepted, and then moves to `rules/`.
Proposals from the Rule Set page or the issue form are copied here as a batch before review.

Reviewed batches: Izzy's Symmetry & Mirror rules (#29 to #29D) became R36 to R40 in 2.0.0;
see `sources/2026-11-21-izzy-symmetry-candidates.md`.
